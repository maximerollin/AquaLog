# AquaLog support

No hosted support service or public support URL is configured in this repository. The app states
that explicitly instead of opening an invented destination. A distributor must configure and
publish its own support destination through `AQUALOG_DEV_SUPPORT_URL` before release. Local data and portable export remain usable
without that service.


Configuration names above refer to development. Use `AQUALOG_BETA_` and
`AQUALOG_PROD_` for the corresponding builds; global `AQUALOG_*` integration
values are not used. See the [environment matrix](v1-closed-test-qualification.md#environnements-android).
